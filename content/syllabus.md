# Machine Learning & AI Engineer Micro Syllabus

The micro syllabus is designed to provide a structured learning path for aspiring ML Engineers and AI Scientists.

## Topics covered

| Unit | Content/topics covered                                                                                                      | Text book | Chapter / section no. | Page number |
| ---- | --------------------------------------------------------------------------------------------------------------------------- | --------- | --------------------- | ----------- |
| I    | Prerequisites: Python Fundamentals, OOP Concepts, Variables, Data Types, Loops, Conditionals, Functions, Exception Handling | [T1]      | 1–3                   | 1–45        |
| I    | Mathematics for ML: Linear Algebra (Vectors, Matrices, Tensors, SVD, Eigenvalues), Calculus (Derivatives, Chain Rule, Gradients) | [T2]      | 2–4                   | 50–120      |
| I    | Probability & Statistics: Bayes Theorem, Random Variables, Distributions, Descriptive Stats, Hypothesis Testing             | [T2]      | 5                     | 121–160     |
| I    | Data Science Libraries: NumPy (Arrays, Broadcasting), Pandas (DataFrames, Wrangling), Matplotlib, Seaborn                   | [T1]      | 6–8                   | 161–220     |
| I    | Data Preprocessing: Loading (CSV, JSON, Parquet), Cleaning, Missing Values, Feature Scaling, Dimensionality Reduction       | [T3]      | 3                     | 70–95       |
| II   | Supervised Learning Basics: Train-Test Split, Cross-Validation, Bias-Variance Tradeoff, Overfitting vs Underfitting         | [T3]      | 4                     | 96–115      |
| II   | Regression Algorithms: Linear Regression, Polynomial Regression, Logistic Regression, Regularization (Lasso, Ridge, ElasticNet)| [T3]      | 5                     | 116–140     |
| II   | Classification Algorithms: KNN, Decision Trees, Random Forests, Support Vector Machines (SVM), Naive Bayes                  | [T3]      | 6                     | 141–170     |
| II   | Unsupervised Learning: Clustering (K-Means, Hierarchical, DBSCAN), PCA, Autoencoders                                        | [T3]      | 7                     | 171–195     |
| II   | Model Evaluation Metrics: Accuracy, Precision, Recall, F1-Score, Confusion Matrix, ROC-AUC, Log Loss                        | [T3]      | 4                     | 100–110     |
| III  | Deep Learning Fundamentals: Perceptrons, MLPs, Activation Functions (ReLU, Sigmoid, Tanh), Backpropagation, Loss Functions  | [T4]      | 1–3                   | 1–60        |
| III  | Neural Network Architectures: CNNs (Convolution, Pooling, Padding), RNNs, LSTMs, GRUs                                       | [T4]      | 4–6                   | 61–130      |
| III  | Transformers & Attention: Self-Attention Mechanism, Multi-Head Attention, Encoder-Decoder Architecture                      | [T4]      | 7                     | 131–160     |
| III  | Deep Learning Frameworks: PyTorch vs TensorFlow/Keras, Tensor Operations, GPU Acceleration                                  | [T4]      | 8                     | 161–190     |
| III  | Natural Language Processing: Tokenization, Embeddings (Word2Vec, GloVe), BERT, GPT, Fine-tuning LLMs                        | [T5]      | 2                     | 40–80       |
| IV   | MLOps & Deployment: Model Serialization, REST APIs (FastAPI/Flask), Docker, CI/CD for ML                                    | [T5]      | 5                     | 100–130     |
| IV   | Experiment Tracking: MLflow, Weights & Biases, Hyperparameter Tuning (Optuna, Ray Tune)                                     | [T5]      | 6                     | 131–155     |
| IV   | Advanced ML Concepts: Reinforcement Learning, Generative Models (GANs, Diffusion), Transfer Learning                        | [T4]      | 9                     | 191–230     |
